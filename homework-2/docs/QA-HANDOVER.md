**Known issues / not covered**

1. Hosted database is free-tier and scales to zero: first request after idle is slow (1–3 s). Not a bug, but visible.
2. Demo data is shared; concurrent testers see each other's rows. Reset command above.
3. "My page", cart and notification icons are placeholders from the Figma frame (no screens behind them).
4. Likes, rating and review count are seed values only; there is no like / review UI.
5. Thumbnail is a choice of three placeholder covers; no file upload.
6. Session is a signed 8-hour cookie without server-side revocation (training scope).
7. Error-message wording follows the WM style but the WM Error Message List itself is still empty, so it is not an approved list.
8. Tested in Chromium (Playwright) and Chrome on Windows 11; Safari / Firefox not run.

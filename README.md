# Frontend Homework — Sandip Mondal

Submissions for the **TL | AI Frontend Training for All Backend Developers** programme. One folder per homework, each a self-contained Next.js project with its own README, `CLAUDE.md` and QA scripts.

| Homework | Folder | Status |
| --- | --- | --- |

## Run a homework

```bash
cd homework-1
npm install
npm run dev
```

See each folder's README for scripts, states, screenshots and design-check notes.

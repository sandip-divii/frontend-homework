# Frontend Homework — Sandip Mondal

Submissions for the **TL | AI Frontend Training for All Backend Developers** programme. One folder per homework, each a self-contained Next.js project with its own README, `CLAUDE.md` and QA scripts.

| Homework | Folder | Status |
| --- | --- | --- |
| HW1 — Build a screen from a design (Steps 1, 2, 5) | [`homework-1/`](homework-1/README.md) | Done — Bookplate "Premium Paid Services" list + temporary login |
| HW2 — Full feature on a real API (Steps 3–8) | [`homework-2/`](homework-2/README.md) | Done — expert services list / create / details / edit / delete on a real API, TanStack Query, roles, tests, QA report (dev server on port 3001; demo: https://frontend-homework-2-red.vercel.app) |

## Run a homework

```bash
cd homework-1
npm install
npm run dev
```

See each folder's README for scripts, states, screenshots and design-check notes.
